FFmpeg notice
=============

The supplied Python-free Windows build includes FFmpeg 9.0.2 essentials
binaries from gyan.dev. This is a static GPL version 3 build, including
libx264. The complete license is in release/Seonyuldam/ffmpeg/LICENSE;
the exact build configuration and external component list are in
release/Seonyuldam/ffmpeg/README.txt.

FFmpeg source corresponding to the build:
https://github.com/FFmpeg/FFmpeg/commit/946fcce07b

The FFmpeg source repository is available at https://github.com/FFmpeg/FFmpeg.
This application invokes the standalone FFmpeg and FFprobe programs as separate
processes and does not link to FFmpeg libraries. The FFmpeg binaries were
obtained from https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip.

The Seonyuldam Python source is separate from FFmpeg.
